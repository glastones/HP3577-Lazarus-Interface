Προτάσεις Διορθώσεων Κώδικα (Simply_VNA)
=======================================

1. Μονάδα (Unit): misc_function.pas, s2p.pas, screenshot.pas, show.pas, test.pas
-------------------------------------------------------------------------------
* Γραμμές:
  - misc_function.pas: 70, 72
  - s2p.pas: 67, 68, 69, 70, 308, 309
  - screenshot.pas: 101, 102, 105, 107, 132, 145, 153
  - show.pas: 180, 181, 183
  - test.pas: 564
* Πρόβλημα:
  Η συνάρτηση `GetUserDir` δεν εγγυάται ότι επιστρέφει διαχωριστικό φακέλων (trailing path delimiter) στο τέλος της διαδρομής. Σε συστήματα Windows, επιστρέφει συνήθως τη διαδρομή μορφής `C:\Users\Username`. Η απευθείας συνένωση με το `'Desktop'` (δηλ. `GetUserDir + 'Desktop'`) παράγει τη διαδρομή `C:\Users\UsernameDesktop`, με αποτέλεσμα να προκαλούνται σφάλματα εισόδου/εξόδου (I/O Errors) κατά την προσπάθεια προσπέλασης ή αποθήκευσης αρχείων στην Επιφάνεια Εργασίας.
* Προτεινόμενη Αλλαγή:
  Πρέπει να χρησιμοποιηθεί η συνάρτηση `IncludeTrailingPathDelimiter` πριν από τη συνένωση.
  Παράδειγμα αλλαγής (στο misc_function.pas):
  - Πριν:
    AssignFile(F, GetUserDir + 'Desktop' + PathDelim + filename);
  - Μετά:
    AssignFile(F, IncludeTrailingPathDelimiter(GetUserDir) + 'Desktop' + PathDelim + filename);


2. Μονάδα (Unit): test.pas
--------------------------
* Γραμμές: 73, 451
* Πρόβλημα:
  Η εντολή `cboSelect.Items.Assign(DataModule1.ReadFilters)` καλεί τη μέθοδο `ReadFilters` η οποία επιστρέφει ένα νέο αντικείμενο τύπου `TStringList` που δημιουργείται δυναμικά στη μνήμη. Η μέθοδος `Assign` αντιγράφει τα περιεχόμενα, αλλά η αναφορά στο επιστρεφόμενο `TStringList` χάνεται χωρίς να αποδεσμευτεί (free), προκαλώντας διαρροή μνήμης (memory leak) κάθε φορά που η φόρμα δημιουργείται ή εμφανίζεται.
* Προτεινόμενη Αλλαγή:
  - Πριν:
    cboSelect.Items.Assign(DataModule1.ReadFilters);
  - Μετά:
    var
      TempList: TStringList;
    begin
      TempList := DataModule1.ReadFilters;
      try
        cboSelect.Items.Assign(TempList);
      finally
        TempList.Free;
      end;
    end;


3. Μονάδα (Unit): databasemodule.pas
------------------------------------
* Γραμμές: 113-126, 377-393
* Πρόβλημα:
  Στις συναρτήσεις `ReadFilters` και `ReadMeasurementTypes`, αν προκύψει κάποια εξαίρεση κατά την εκτέλεση του ερωτήματος SQL (SQL Query) ή τη σύνδεση στη βάση δεδομένων, το αντικείμενο `Result` (τύπου `TStringList`) που έχει ήδη δημιουργηθεί δεν αποδεσμεύεται, οδηγώντας σε διαρροή μνήμης (memory leak).
* Προτεινόμενη Αλλαγή (για τη ReadFilters):
  - Πριν:
    function TDataModule1.ReadFilters:TStringList;
    begin
      Result:=TStringList.Create;
      try
        self.connecting;
      except
        on E: Exception do
        begin
          Result.Free;
          raise Exception.Create('DataBase Not Found');
        end;
      end;
      self.SQLQuery1.SQL.Text := 'SELECT filter_name FROM filters';
      self.SQLQuery1.Open;
      ...
  - Μετά:
    function TDataModule1.ReadFilters:TStringList;
    begin
      Result:=TStringList.Create;
      try
        self.connecting;
        self.SQLQuery1.SQL.Text := 'SELECT filter_name FROM filters';
        self.SQLQuery1.Open;
        while not (self.SQLQuery1.EOF) do
        begin
          Result.Add(self.SQLQuery1.FieldByName('filter_name').AsString);
          self.SQLQuery1.Next;
        end;
        self.SQLQuery1.Close;
        self.SQLTransaction1.Commit;
      except
        Result.Free;
        raise;
      end;
    end;


4. Μονάδα (Unit): serial.pas
----------------------------
* Γραμμές: 50-80
* Πρόβλημα:
  Τα αντικείμενα `portList` και `configFile` δημιουργούνται πριν από την έναρξη του μπλοκ `try` (γραμμή 80). Εάν προκύψει κάποιο σφάλμα/εξαίρεση ενδιάμεσα (για παράδειγμα, στη γραμμή 76: `raise Exception.Create('No serial ports found on the system')`), η ροή εκτέλεσης θα παρακάμψει το `try...finally` με αποτέλεσμα τα `portList` και `configFile` να μην αποδεσμευτούν ποτέ από τη μνήμη.
* Προτεινόμενη Αλλαγή:
  Το μπλοκ `try` πρέπει να ξεκινά αμέσως μετά τη δημιουργία των αντικειμένων αυτών.
  - Πριν:
    portList:=TstringList.Create;
    ...
    configFile:=TIniFile.Create(...);
    ...
    if not found then begin
      ...
      raise Exception.Create('No serial ports found on the system');
    end;
    try
      try
        self.LazSerial1.Active := True;
        ...
      finally
        configFile.Free;
        portList.Free;
      end;
  - Μετά:
    portList:=TstringList.Create;
    try
      configFile:=TIniFile.Create(ExtractFilePath(application.Params[0])+'settings.ini');
      try
        ...
        if not found then begin
          ...
          raise Exception.Create('No serial ports found on the system');
        end;
        self.LazSerial1.Active := True;
        ...
      finally
        configFile.Free;
      end;
    finally
      portList.Free;
    end;
